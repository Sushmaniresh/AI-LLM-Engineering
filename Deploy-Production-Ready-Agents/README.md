## 🎯 What the path covers
- **Agent lifecycle:** taking an agent from prototype to production and managing it there
- **Deployment:** running agents on Vertex AI Agent Engine and Cloud Run
- **Enterprise connectivity:** Model Context Protocol (MCP) for tools and data, Agent2Agent (A2A) for agent-to-agent communication
- **Agent Development Kit (ADK):** Google's framework for building the agents, used in the challenge lab
