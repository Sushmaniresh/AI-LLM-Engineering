## TL;DR

- **Must-haves** (asked by half or more of entry-level roles): Python, LLM fundamentals, **AI agents**, prompt engineering, **RAG**, REST APIs, SQL, JS/TS, CI/CD, Git, AI coding tools.
- **My biggest gaps:** tool/function calling, MCP, LangGraph, LLM observability (Langfuse/LangSmith), guardrails/responsible AI, TypeScript, Azure.
- **Interviews:** LLM + agent concept questions, LeetCode-style coding, a 2–4 hr take-home (usually RAG or an agent), AI system design, and a deep-dive on past projects.
- **Resume:** use the postings' keywords (*AI agents, agentic workflows, tool use / function calling, RAG, evaluation*), add a metric to every bullet, and add a Projects section for the course builds.
